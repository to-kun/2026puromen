# 小出市役所 公式ホームページ（異変探しゲーム）

8番出口ライクな、変化（異変）を見つけて脱出を目指すWebゲームです。  
小出市役所の公式ホームページを模したサイト内を観察し、異変の有無を正しく判定して階層 8 からの脱出を目指します。

---

## 🎮 ゲームルール

1. **基本ルール**
   - プレイヤーは小出市役所のホームページ内を探索します。
   - ページ内に「異変（通常と異なる点）」があるか注意深く確認します。
   - ナビゲーションの **「報告・お問い合わせ」** タブから異変の有無を選択・報告します。
     - **異変がある** と思った場合：`異変がある` ボタンを押す
     - **異変がない** と思った場合：`異変はない` ボタンを押す
   - **正解** すると次の階層へ進みます（階層 8 に到達すると脱出成功）。
   - **不正解** になると振り出し（階層 0）に戻されます。

2. **初回プレイ（階層 0）**
   - 初回開始時（`階層 0`）は、正解の基準となる状態を確認できるよう **必ず「異変なし」** に設定されています。

3. **振り返り機能**
   - 初回プレイ以外のゲーム進行中や失敗時、画面A（案内画面）に **「直前のページを振り返る」** ボタンが表示されます。
   - このボタンを押すと、判定に影響を与えない閲覧専用モードで直前のページ状態を再確認できます。

## 💾 ローカルに情報保存

ブラウザの `localStorage` API を利用し、サーバーを介さずクライアントサイドのみで進行状況やデータを永続化します。

- **保存対象データ**
  - **最高到達階層（`maxStep`）**: 過去最高で到達した階層データ。
  - **クリアフラグ（`hasCleared`）**: 脱出成功（階層 8 クリア）の達成状態。
  - **異変の出現重み（`anomalyWeights`）**: 各異変IDごとの出現確率の重み付け値。
- **データ管理仕様**
  - ゲーム起動時に `localStorage` から保存データを取得し、初期化を行う。
  - 判定結果の更新時およびクリア達成時に該当するキーの値を更新・保存する。
  - 全ての異変が出現し終えた場合やプレイヤーによるデバッグ操作時には、保存された重みデータのリセット（削除）を可能とする。

## 🎲 異変の選択

重複発生の偏りを防ぎ、未体験の異変を優先的に体験させるための「重み付きランダム選出アルゴリズム」を採用します。

- **発生確率の判定**
  - 各ステップ開始時、50%の固定確率で「異変あり」か「異変なし（通常）」かを決定する（※階層 0 は必ず「異変なし」）。
- **重み（Weight）ベースの選出**
  - 全異変には初期重み（例: `100`）が設定されている。
  - 「異変あり」と判定された場合、各異変の現在の重み総和からランダム数値を算出し、比率に応じた確率で1つの異変を選出する。
- **出現後の減衰処理**
  - 一度選出されて発生した異変は、次回以降の出現率を下げるために重み値を減衰（例: 現在値の 20% へ減算）させる。
  - 減衰された重みデータは即座に `localStorage` へ更新保存される。

## ⚡ 異変発生時の動作

異変の規模や対象要素に応じて、軽量なDOM書き換えから全体HTML置換までを統一したインターフェースで制御します。

- **通常異変（要素単位の描画変更）**
  - 対象DOM要素のテキスト置換、CSSクラスの動的付与・削除、画像パス（`src`）の差し替えを実行。
  - `AnomaliesManager` が各異変の定義に含まれる `apply`（発動）および `reset`（復元）処理を呼び出すことで制御する。
- **大規模異変（テンプレート置換）**
  - ページ全体・広範囲に及ぶ異変の場合、`fetch` APIを利用して該当する非同期HTMLテンプレート（`static/anomalies/` 配下等）を取得。
  - 元のDOM構造をメモリ上にバックアップした上で、メインコンテナ（`#app` 等）の `innerHTML` を置換する。
- **復元処理の担保**
  - 次のステップへの遷移時には、前回の異変フラグに基づいて `reset` 処理または元のDOM構造への再展開を実行し、完全に「異変なし」の初期状態へ戻してから新たな判定を行う。

## 📝 開発メモ・注意事項

- **JavaScriptの依存関係**  
  `index.html` 内でのスクリプト読み込み順序は以下の通りです。
  1. `anomalies.js`
  2. `gameLogic.js`
  3. `main.js`


- **GitHub Pages対応**  
  静的ホスティング環境で動作させるため、異変データはAPI経由ではなく `anomalies.js` 内でJavaScriptオブジェクトとして直接管理されています。


-**投稿者用コマンド**
  Microsof EdgeやGoogle chrome等のブラウザから、開発者ツールを押す
  そこで以下のコマンドが対応

  -異変の強制発生・リセット
    任意の異変を手動で発動させたり、正常状態に戻すコマンド。

    -指定したIDの異変を強制発動
      ```JavaScript
      window.debugSetAnomaly("01"); // 01を任意の異変ID（文字列）に書き換えて実行
      ```

    -異変なし（正常状態）に強制リセット
      ```JavaScript
      window.debugSetAnomaly(0);
      ```
  
  -セーブデータ・図鑑の操作（StorageManager）
    localStorage に保存されているセーブデータの取得や直接書き換え。

    -図鑑の解放状況（配列）を取得
      ```JavaScript
      window.StorageManager.getUnlockedAnomalies();
      ```
    
    -特定の異変IDを図鑑に手動解放
      ```JavaScript
      window.StorageManager.saveUnlockedAnomaly("01"); // "01" 部分を解放したいIDに変更
      ```
    -現在の最高到達階層を取得
      ```JavaScript
      window.StorageManager.getMaxStep();
      ```

    -最高到達階層を書き換え
      ```JavaScript
      window.StorageManager.saveMaxStep(8); // 指定した階層数に変更
      ```
    -全セーブデータの一括消去（完全初期化）
      ```JavaScript
      localStorage.clear();
      location.reload(); // 消去後に自動リロード

  -ゲーム進行状態の直接書き換え（GameLogic）
    進行中の内部フラグや階層を直接操作するコマンド。

    -現在の階層を変更
      ```JavaScript
      window.game.currentStep = 5; // 任意の階層数
      ```

    -現在の階層判定（異変の有無）を直接変更
      ```JavaScript
      window.game.hasAnomaly = true; // true: 異変あり / false: 異変なし
      ```

    -強制的にクリア画面を表示
      ```JavaScript
      window.game.currentStep = 8;
      window.game.makeChoice(true); // 直前の異変有無に合わせて実行

  -データ確認コマンド（AnomalyManager）
    CSVから読み込まれた異変データ一覧や、現在アクティブな異変データの確認。

    -読み込まれている全異変データを出力
      ```JavaScript
      console.table(window.AnomalyManager.anomalies);
      ```

    -現在画面に適用されている異変のオブジェクトを取得
      ```JavaScript
      console.log(window.AnomalyManager.activeAnomaly);
      ```
